# Task 4.1 — Alert System

## Overview

`alerter.py` is a Python script that sends automated email and Discord alerts when **new HIGH severity findings** are detected in a security audit diff report. It is designed to run as part of the automated audit pipeline defined in `run_audit.sh`.

---

## Files

| File | Description |
|------|-------------|
| `alerter.py` | Main alerting script |
| `run_audit.sh` | Pipeline orchestrator that calls `alerter.py` |
| `config.json` | Configuration file for email credentials, recipients, and Discord webhook |

---

## Requirements

- Python 3.10+
- A Gmail account with [App Passwords](https://support.google.com/accounts/answer/185833) enabled (or a local Postfix setup)
- A Discord webhook URL (see [Discord Webhooks documentation](https://support.discord.com/hc/en-us/articles/228383668-Intro-to-Webhooks))
- A diff report JSON file generated by `diff_reports.py`
- `requests` library: `pip install requests`

---

## Configuration

Create a `config.json` file with the following structure:

```json
{
    "email_from": "examplen.cender@gmail.com",
    "email_to": "example.resiever@gmail.com",
    "email_password": "password 123",
    "discord_webhook": "https://discord.com/api/webhooks"
}
```

---

## Usage

```bash
python3 alerter.py <path_to_diff_file.json> <path_to_config.json>
```

**Example:**

```bash
python3 alerter.py /var/reports/diff/diff_report_2025-06-01.json /path/to/config.json
```

---

## How It Works

1. Parses the diff JSON file produced by `diff_reports.py`
2. Looks through the **"New findings"** section for any entries with `"Severity": "HIGH"`
3. If new HIGH findings exist, sends both an **email alert** and a **Discord message** summarising:
   - The date and time of detection
   - The number of new HIGH findings
   - Each finding's check name and affected path/value
   - A path to the full HTML report
4. If no new HIGH findings are found, prints a confirmation and exits cleanly

**No alert is sent for findings that were already present in the previous run** — only *new* HIGH findings trigger a notification.

## Example Alert

The following is sent both as an email and as a Discord channel message:

```
🚨 New HIGH severity findings:

- date: 2025-06-01 03-00-12
- New HIGH findings: 2

[HIGH] Open backdoor port : port : 4444 | protocol : tcp |

[HIGH] World-writable file : path : /etc/cron.daily/check |


View full report: /var/reports/report_2025-06-01.html
```

---

## Integration with `run_audit.sh`

`alerter.py` is automatically called by `run_audit.sh` after the diff report is generated:

```
run_audit.sh
 └─> audit.py              → findings_YYYY-MM-DD.json
 └─> diff_reports.py       → diff_YYYY-MM-DD.json
 └─> alerter.py            → sends email + Discord message if new HIGH findings exist
 └─> report_generator.py   → report_YYYY-MM-DD.html
```

---

## Error Handling

- Exits with a clear message if a non-JSON file is passed for either argument
- Prints a failure message if the email or Discord notification cannot be sent (e.g. network unavailable, wrong credentials, invalid webhook URL) without crashing the pipeline
